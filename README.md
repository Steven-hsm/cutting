# Cutting — Windows 截图工具

基于 Electron 的 Windows 截图工具：全局快捷键截图、区域选择、多种标注、贴图置顶、保存到指定目录并复制到剪贴板，支持可持久化、可搜索、可滚动的截图历史。

> 📖 完整操作手册见 [MANUAL.md](MANUAL.md)

## 功能

### 截图与取图方式

- **全局快捷键截图**：默认 `F1`（可在设置中修改，支持冲突检测与回滚）
- **贴图（剪贴板）快捷键**：默认 `F3`，把剪贴板中的图片 / 文字 / 颜色直接贴到屏幕顶层
- **取图方式**（托盘菜单，各项平铺并在右侧显示快捷键）：
  - 区域截图（`F1`，拖拽选区）
  - 全屏截图（自动选中整个屏幕，可直接编辑保存）
  - 活动窗口（自动识别最上层窗口并居中选中）
  - 上次区域（复用上一次的选区）
  - 延时截图（按设置延时 0/3/5/10 秒后进入截图，便于捕捉展开的菜单）
  - 贴剪贴板内容（`F3`）
- **录制 GIF / 滚动截图**：在截图工具栏中点击「GIF」「滚动」图标即可对当前选区执行（托盘菜单不提供入口）
  - 两种模式都会在选区外侧保留完整边框（GIF 为 REC 红色标记、滚动为 SCROLL 蓝色标记），边框不覆盖选区，因此不会进入录屏或拼接结果
  - GIF：生成循环 GIF（默认 10 FPS，最长 60 秒）；保存后会自动把 GIF 文件写入剪贴板，按 `F3` 即可把刚录制的 GIF 以动画贴图贴到屏幕（保存后 8 秒内按 F3 会优先贴这条最新 GIF，并且**贴回录制时的原位置与尺寸**，不受剪贴板残留内容影响；历史记录中的 GIF 贴图同样按原录制位置放置）
  - 滚动截图：自动向下滚动并拼接长截图，检测到无法继续滚动时自动结束并保存
- **从图片编辑**：历史窗口拖入图片文件，或点击「编辑剪贴板图片」，即可进入同一套标注编辑器
- **OCR 文字识别**（借鉴 QQ / PixPin / ShareX）：使用 Windows 本地离线 OCR；识别后文字按原位置覆盖在截图上，**直接拖动选中即可 `Ctrl+C` 复制**，也可「复制全部」；贴图窗口按 `O` 同样可原地选字，历史记录「识图」在结果窗口中查看
- **多显示器 / 高分屏**：同时在所有显示器上打开截图遮罩，可在任意一块屏幕上框选；按物理像素抓屏，高 DPI 下图像清晰

### 截图界面（Snipaste 风格）

- **图标式浮动工具栏**：工具分组 + 悬停提示，选中工具后展开「颜色 / 粗细 / 字号」样式行
- **调色板**：5 个常用色 + 自定义取色器（任意颜色），文字与图形共用当前颜色
- **窗口识别**：鼠标悬停在窗口上会高亮边框，单击即可直接选取整个窗口（拖动仍为自由选区）
- **放大镜 + 取色器**：跟随光标的像素级放大镜，显示 HEX/RGB 色值；`Alt` 显示/隐藏，`Shift` 切换格式，`C` 复制颜色
- **尺寸徽标**：选区左上角实时显示物理像素尺寸
- **截图美化**（借鉴 PixPin）：保存/复制时可自动添加圆角、投影、纯色或渐变背景与文字水印（设置中开启）

### 标注与编辑

- 拖拽选择截图区域；选中后可拖动选区移动，或拖动 8 个控制点调整大小
- **方向键微调**：方向键移动选区 1px，`Ctrl+方向键` 扩大，`Shift+方向键` 缩小
- 标注工具（支持单键快捷切换）：
  - **文字**（T）：多行输入，5 种颜色、3 种字号
  - **矩形（R）/ 椭圆（O）/ 箭头（A）/ 直线（L）**：5 种颜色、3 种粗细，`Tab` 在直线与箭头间切换
  - **画笔（P）**（自由绘制，`Shift` 画直线）、**荧光笔（H）**（半透明高亮）
  - **序号（N）**：点击自动放置 ①②③
  - **马赛克（M）**：基于原图像素生成，细/中/粗三档笔刷
  - **高斯模糊（B）**：拖拽框选需要模糊的区域，弱/中/强三档
- **滚轮 / `[` `]`** 调整当前工具的粗细、字号或笔刷大小；**右键**结束当前正在绘制的图形
- 撤销 / 重做（工具栏按钮，`Ctrl+Z` / `Ctrl+Y`）

### 保存、贴图与历史

- **截图完成后动作**（可配置）：保存到目录 + 复制到剪贴板 / 仅保存 / 仅复制 / 直接贴图
- **图片格式**：PNG（无损）/ JPG（有损）/ WebP，JPG 可设置压缩质量
- **文件名模板**：支持 `{yyyy} {MM} {dd} {HH} {mm} {ss} {ms}` 变量，重名自动追加序号
- **贴图（置顶展示）**：将选区以置顶窗口固定在屏幕上；可拖动（自动吸附屏幕与其他贴图边缘）、滚轮缩放、`Ctrl+滚轮` 调透明度、`Ctrl+C` 复制、`O` 识别文字、`X` 鼠标穿透；数字键 `1`-`4` 旋转、`5`/`6` 翻转、双击关闭、`Shift+双击` 缩略图模式；也可把剪贴板图片/文本/颜色贴到屏幕
- **截图历史**：默认 `Ctrl+Alt+H` 唤起/隐藏（`Esc` 也可隐藏），网格可滚动；支持关键字搜索、收藏筛选、复制、贴图、打开文件位置、删除；**GIF 可复制为文件**（直接粘贴到聊天/资源管理器）并以**动画贴图**形式置顶
- **GIF 与滚动截图**：截图工具栏的「录GIF」「滚动截图」按钮可直接对当前选区执行；录制时可用控制条或 `Esc` 停止；滚动截图的每步滚动格数与间隔可在设置中调整
- **打开历史目录**：默认 `Ctrl+Alt+D`，在资源管理器中打开历史索引与缩略图目录（托盘菜单也有入口）
- **历史持久化**：历史索引与缩略图保存在 `%APPDATA%\Cutting\history`，重启后仍可查看；超出上限自动清理最旧记录
- **设置**：快捷键录制、截图延时、完成后动作、图片格式与质量、文件名模板、滚动截图步长与间隔、截图美化（圆角/投影/背景/水印）、保存目录、历史记录上限、历史窗口置顶、开机自启（打包安装后生效）

## 使用

```bash
npm install
npm start
```

启动后静默驻留系统托盘，不会打开任何窗口，直接按 `F1` 即可截图。设置、历史等功能可从托盘菜单或快捷键进入；关闭所有窗口后程序仍继续驻留托盘。

贴图窗口：拖动移动、滚轮缩放、`Ctrl+滚轮` 透明度、`X` 鼠标穿透、`Ctrl+C` 复制、`O` 识别文字（拖动选字后 `Ctrl+C` 复制）、`1`-`4` 旋转、`5`/`6` 翻转、双击关闭、`Shift+双击` 缩略图模式、`Esc` 关闭。

## 打包

```bash
npm run dist
```

使用 electron-builder 生成 Windows NSIS 安装包（输出到 `dist/`，安装包文件为 `Cutting Setup 0.1.0.exe`）。开机自启仅在安装后的正式版本中生效。

若下载 Electron 或打包工具较慢，可设置镜像后再执行：

```bash
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ \
ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/ \
npm run dist
```

## 数据位置

- 设置：`%APPDATA%\Cutting\settings.json`
- 历史索引：`%APPDATA%\Cutting\history\index.json`
- 缩略图：`%APPDATA%\Cutting\history\thumbs\`
- 截图原图：设置中的保存目录（默认 `图片\Cutting`）

## 开发说明

- 纯 JavaScript，无构建步骤；主进程代码位于 `src/main`，渲染层位于 `src/renderer`（`overlay` 截图编辑、`pin` 贴图、`history` 历史、`settings` 设置、`recorder` GIF 录制、`scroll` 滚动截图、`ocr` 识别结果），预加载脚本位于 `src/preload`。
- 已适配 Electron 44 的异步剪贴板 API（`clipboard.write([new ClipboardItem(...)])`）。
- 编辑采用操作列表重放实现撤销/重做；马赛克只重绘笔画包围盒并按帧合并移动事件，大选区下依然流畅。
- 活动窗口截图通过 PowerShell + User32 查询前台窗口后匹配 `desktopCapturer` 源；OCR 通过 PowerShell 调用 Windows.Media.Ocr 离线识别。
- 可通过环境变量 `CUTTING_USER_DATA` 指定独立数据目录，便于测试或便携使用。
- 托盘图标由 `npm run icon`（`tools/make-icon.js`）生成。

## 已知限制

- OCR 依赖 Windows 自带语言包；若提示未安装，请在「设置 > 应用 > 可选功能」中添加「中文(简体) OCR」。暂不支持文字翻译与表格识别。
- 暂不支持一次拖拽跨越两块显示器选区（可在任意一块屏幕上分别框选）。
- 滚动截图依赖滚轮事件，对不支持滚轮滚动的应用（如部分游戏、画布应用）无效；滚动时鼠标会被移动到选区内。
- GIF 录制最长 60 秒、宽度上限 1000px，超出会自动结束；不支持麦克风/系统声音。
- 全屏独占游戏等特殊窗口可能无法被置顶覆盖。
